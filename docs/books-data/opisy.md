1. PHP5. Programowanie
Autorzy: Rasmus Lerdorf, Kevin Tatroe, Peter MacIntyre
Wydawnictwo: O’Reilly / Helion
ISBN: 978-83-246-0613-9
Cena widoczna na książce: 64,90 zł
Kategoria: PHP / Backend / Programowanie
Krótki opis:
Kompleksowy podręcznik języka PHP 5 napisany m.in. przez twórcę PHP, Rasmusa Lerdorfa. Obejmuje podstawy składni, programowanie obiektowe, pracę z bazami danych, XML, grafiką oraz zagadnienia bezpieczeństwa aplikacji internetowych.
Pełniejszy opis:
Książka przedstawia PHP 5 od podstaw języka aż po bardziej zaawansowane techniki tworzenia aplikacji internetowych. Omawia strukturę i składnię PHP, przetwarzanie tekstu i wyrażenia regularne, programowanie obiektowe, sesje i komunikację HTTP, współpracę z bazami danych, generowanie grafiki, XML oraz zabezpieczanie aplikacji. Jest to interesująca pozycja również z historycznego punktu widzenia — pokazuje sposób budowania aplikacji webowych w czasach, gdy PHP 5 był jednym z podstawowych narzędzi dynamicznego WWW.
2. PHP. Obiekty, wzorce, narzędzia. Wydanie IV
Autor: Matt Zandstra
Wydawnictwo: Apress / Helion
ISBN: 978-83-246-9178-4
Cena widoczna na książce: 79,00 zł
Kategoria: PHP / OOP / Wzorce projektowe / Software Engineering
Krótki opis:
Książka poświęcona obiektowemu PHP, wzorcom projektowym i narzędziom pomagającym tworzyć większe, dobrze zorganizowane aplikacje. Dobry krok od znajomości samej składni PHP w stronę projektowania oprogramowania.
Pełniejszy opis:
Pozycja koncentruje się na programowaniu obiektowym w PHP oraz projektowaniu aplikacji, które można łatwiej rozwijać i utrzymywać. Omawia klasy i obiekty, najważniejsze wzorce projektowe, dobre praktyki oraz typowe problemy pojawiające się podczas rozwijania większych projektów. Porusza również zagadnienia związane z PEAR, PHPUnit, automatycznym generowaniem dokumentacji oraz testami jednostkowymi. Szczególnie przydatna dla programisty, który chce przejść od pisania pojedynczych skryptów do świadomego projektowania architektury aplikacji.
3. PHP i MySQL. Tworzenie stron WWW. Vademecum profesjonalisty. Wydanie trzecie
Autorzy: Luke Welling, Laura Thomson
Wydawnictwo: Helion
ISBN: 83-7361-784-1
Cena widoczna na książce: 99,00 zł
Kategoria: PHP / MySQL / Backend / Web Development
Krótki opis:
Praktyczny podręcznik tworzenia dynamicznych stron WWW z wykorzystaniem PHP i MySQL. Łączy naukę języka PHP z projektowaniem baz danych oraz tworzeniem kompletnych aplikacji internetowych.
Pełniejszy opis:
Obszerne vademecum dotyczące tworzenia dynamicznych serwisów internetowych przy użyciu PHP i MySQL. Książka obejmuje podstawy PHP, programowanie obiektowe, projektowanie i obsługę baz danych MySQL, operacje na danych, formularze, personalizację witryn, mechanizmy komunikacji i bezpieczeństwo aplikacji WWW. Pokazuje pełny model klasycznej aplikacji webowej: od interfejsu i formularza, przez logikę PHP, aż do trwałego przechowywania danych w bazie.
